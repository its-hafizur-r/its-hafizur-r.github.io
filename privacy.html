Privacy policy

Last updated 23 November 2026

This website is the personal link page and media kit of the TikTok creator @hafizur_r.

What this site uses

The site uses the TikTok API to read only the site owner's own TikTok account: public profile details (name, avatar), account totals (followers, following, likes, video count) and the owner's own public videos with their view, like, comment and share counts. These numbers are shown on the media kit page.

It does not read anyone else's account, messages or private data, and it never posts, edits or deletes anything on TikTok.

Visitors

The site has no sign-up, no forms and no tracking or advertising cookies. It is hosted on GitHub Pages, which may keep standard server logs (such as IP addresses) for security; see GitHub's privacy statement. Fonts load from Google Fonts.

Storage and deletion

The TikTok access token is stored as an encrypted GitHub Actions secret and is used once a day to refresh the numbers. The owner can disconnect at any time from TikTok's settings (Security and permissions, Manage app permissions), after which the data stops updating and can be deleted from the site.
